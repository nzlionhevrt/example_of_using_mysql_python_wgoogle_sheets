Тестовое задание: MySQL + Python + Google Sheets + Yandex DataLens
Задание направлено на то, чтобы свести два различных источника данных в один и отобразить это на дашборде.
1. Сервер и MySQL
Мы предоставляем:
•	адрес сервера,
•	логин/пароль SSH (или ключ).
Задача
1.	Установить MySQL на выданный сервер.
2.	Создать БД:
analytics_test
3.	Создать пользователя:
analytics_user / <любой_пароль>
3.	Настроить доступ из DataLens (открыть порт 3306).

2. Таблица факта (продажи)
Создать таблицу:
CREATE TABLE sales_fact (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    sale_date       DATE NOT NULL,
    club_id         INT NOT NULL,
    club_name       VARCHAR(255) NOT NULL,
    revenue         DECIMAL(12,2) NOT NULL,
    contracts_count INT NOT NULL,
    created_at      DATETIME NOT NULL,
    updated_at      DATETIME NOT NULL
);
Требования к данным – наполнить таблицы не менее чем 3 клубами любым удобным способом (чисто для демонстрации)
3. План от продаж (Google Sheets → MySQL)
3.1. Создать Google-таблицу
Структура таблицы:
month	club_id	club_name	plan_revenue
2025-09-01	1	Club A	5 000 000
2025-09-01	2	Club B	4 000 000
2025-09-01	3	Club C	3 500 000
…	…	…	…
Требования:
Должны быть строки по каждому клубу.
3.2. Таблица в MySQL
Создать таблицу:
CREATE TABLE revenue_plan (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    month        DATE NOT NULL,
    club_id      INT NOT NULL,
    club_name    VARCHAR(255) NOT NULL,
    plan_revenue DECIMAL(12,2) NOT NULL,
    created_at   DATETIME NOT NULL,
    updated_at   DATETIME NOT NULL
);
Написать Python-скрипт load_plan_from_sheets.py, который:
Функциональность:
1.	Подключается к Google Sheets (любой официальный способ, проще всего распубличить).
2.	Читает данные таблицы.
3.	Подключается к MySQL.
4.	Делает UPSERT:
o	обновляет, если (month, club_id) существует,
o	иначе вставляет запись.
Требования:
•	Использовать .env для настроек (MySQL, Google credentials).
•	В проекте должны быть:
o	requirements.txt
o	README.md с инструкцией запуска.
4. DataLens 
Кандидат самостоятельно:
1.	Регистрируется в Yandex DataLens (бесплатно).
2.	Создаёт подключение к MySQL с сервера.
3.	Создаёт объединённый датасет ds_plan_fact.
5. Построить дашборд в DataLens
Нужно создать 5 чартов:
1. Индикатор: Фактическая выручка
•	Значение: SUM(fact_revenue)
•	Подпись: «Фактическая выручка сети»
•	Формат: ₽ с разделителями разрядов
2. Индикатор: % выполнения плана
•	Значение:
SUM(fact_revenue) / SUM(plan_revenue) * 100
•	
•	Подпись: «Выполнение плана, %»
•	Формат: проценты
•	Цветовое выделение (желательно):
o	<90% — красный
o	90–100% — жёлтый
o	100% — зелёный
3. Таблица: План vs Факт по клубам
Колонки:
•	month
•	club_name
•	plan_revenue
•	fact_revenue
•	revenue_delta
•	revenue_plan_completion
4. Столбчатая диаграмма: «План и факт по клубам»
•	X: club_name
•	Y: выручка
•	Серии:
o	fact_revenue
o	plan_revenue
5. Линейный график: «Динамика план/факт по месяцам»
•	X: month
•	Y: выручка
•	Серии:
o	fact_revenue
o	plan_revenue
